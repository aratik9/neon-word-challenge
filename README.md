⚡ Neon Word Challenge

A futuristic word puzzle game featuring a neon gaming interface, glowing effects, and fast-paced word challenges. Test your vocabulary, beat the clock, and level up!

🎮 Live Demo

Play the game online: https://YOUR-USERNAME.github.io/neon-word-challenge/

Replace YOUR-USERNAME with your GitHub username after enabling GitHub Pages.
✨ Features
🌌 Futuristic neon cyan and pink UI
🧩 Unscramble words and test your vocabulary
⏱️ 30-second countdown timer
🏆 Score tracking and level progression
💡 Hint system for difficult words
🔄 Skip and restart options
📱 Responsive design for mobile and desktop
⚡ Built with pure HTML, CSS, and JavaScript
🛠️ Technologies Used
HTML5 — Game structure
CSS3 — Neon styling, glow effects, and animations
JavaScript — Game logic, scoring, hints, and timer

Open your repository on GitHub.

Select Deploy from a branch.
Choose the main branch and /(root) folder.
Click Save.
Visit your published GitHub Pages URL.
🎯 How to Play
Look at the scrambled word displayed on the screen.
Type the correct word in the input box.
Click Submit or press Enter.
Use hints if you need help.
Earn points, advance levels, and beat the timer!
Scoring
Correct answer: +10 points
Correct answer after using a hint: +5 points
Incorrect answer: −2 points
Skip a word: −3 points
Level up: Every 50 points
